# Admin guide (for HKNR staff)

Sign in at **/admin/login** with the email and password an administrator gave you. There is no public sign-up.

## Roles

- **Staff**: enquiries, properties, projects, photos, services, localities.
- **Administrator**: everything staff can do, plus website settings, staff accounts, the activity log, and permanent deletion.

## Daily: handle enquiries

1. **Dashboard** shows new enquiries, unassigned ones and follow-ups due.
2. Open an enquiry. Use **Call**, **WhatsApp** or **Email** to reply. Note the visitor's preferred method.
3. Set **Status**: New → Contacted → Follow-up → Qualified → Closed (or Spam). Assign it to yourself and set a **Next follow-up** date if needed. Click **Save**.
4. Add a **note** after every conversation. Only staff can see notes.
5. Enquiries marked **Spam** automatically are kept, not deleted. Check the Spam tab now and then in case a real one was caught.

## Add a property

1. **Properties → Add property**. Fill in the basics. Only the fields that suit the property type are shown.
   - **Price**: whole rupees (e.g. `7500000` = ₹75 lakh). The form shows how it will appear. Tick **Price on request** to hide the figure.
   - **Plot area** in sq yd (usual for Hyderabad plots). **Built-up** = floor area including walls; **Carpet** = usable area inside the walls.
   - **Exact address** is private; the website only shows the **Public location note**.
   - **Approvals / RERA**: enter only what you have documents for.
2. **Save draft and add photos**. If it looks like an existing listing, you'll be asked to confirm. Nothing is ever merged automatically.
3. **Photos**: upload several at once. The first photo is the cover; use **Move up / Make cover** to reorder. Add a short description for each photo (e.g. "Kitchen with window to the east").
4. **Preview**, then **Publish**. Publishing needs a price (or price on request), a description of 40+ characters, and at least one photo.

### Photo standards
- Real photos of this property only, taken in daylight, landscape, at least 1600 px wide where possible.
- Lead with the front elevation or the plot, then the main rooms, kitchen, bathrooms and the view or street.
- No watermarks or heavy filters. Phone location data is removed automatically.

## When a property is sold or withdrawn

- **Mark sold / Mark under offer** (right-hand panel): the listing stays visible with a badge and sorts after available ones.
- **Unpublish** hides it from the website; it stays in admin as a draft.
- **Archive** hides it from the default admin list too. **Delete permanently** (admins only) removes it and its photos. Enquiries about it are kept.

## Projects (construction portfolio)

Same flow as properties: add details → photos → publish. Publish only genuine HKNR projects, with the client's permission to show them. Specifications are one per line, `Label: value`.

## Services and localities

- **Services**: what HKNR offers in construction. Set them to Published to show them on the Construction page.
- **Localities**: add each area you list in (e.g. Moula Ali). Visitors only see a locality in filters once it has a published listing. A locality can't be deleted while listings use it.

## Settings (administrators)

- **Phone / WhatsApp / Email**: the website shows Call and WhatsApp buttons only when these are filled in. Enter verified numbers only.
- **Send new enquiries to**: internal email for notifications (requires the email service to be configured).
- **Address**: shown publicly only if **Show the address publicly** is ticked.
- **Home page image**: a genuine photograph. Without one, a drawn illustration is shown.
- **Registrations**: e.g. TS-RERA agent registration number, shown in the footer.

## Staff accounts (administrators)

Create accounts with a temporary password, shared privately. Ask the person to change it under **Account**. Deactivate accounts of people who leave; this signs them out everywhere. At least one administrator must remain active.

## If something goes wrong

- Errors are explained in plain language and your typed text is kept. Fix the highlighted fields and try again.
- "Session expired": sign in again.
- Photo rejected: follow the message (too big, too small or not an image).
- Anything else: check **Activity log** (admins) to see recent changes.
